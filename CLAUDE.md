Issues live as GitHub issues on `nanov/protobuf-to-messagepack-sharp`, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical roles, each label string equal to its name. See `docs/agents/triage-labels.md`.

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Language spec

`docs/spec/protop.md` is an **index**, not the spec. Its table names one file per
section and says which task needs which. Read the sections the task names and
stop; the whole spec is four times the size of any one job in it.
